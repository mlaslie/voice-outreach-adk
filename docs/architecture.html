What happens on a call

  1. A nurse starts a call or a run in the dashboard, or the every-minute timer finds one that is due. The API checks the allowlist, the budget and calling hours, then queues a dial task.
  2. The API asks Twilio to call the patient. Twilio streams the call audio to the gateway.
  3. The gateway runs the ADK voice agent on Gemini Live. It speaks first, checks the date of birth with a tool (the model never sees it), then asks each question.
  4. Every answer goes through a tool. The tool turns the answer into a standard value, and triage (code, not the model) decides same day, next business day or noted.
  5. The report is saved to Firestore with the transcript, timeline and recording. The dashboard and the nurse agent show it straight away.

If nobody answers

  1. Voicemail: the gateway plays a fixed message (no patient details) and hangs up.
  2. A minute later the API texts the patient (consent, allowlist and this system holding the number are all required): 1 to be called now, 2 to pick a time, 3 to answer by text.
  3. Answering by text uses the same questions and the same triage as the call, so a text report looks the same as a call report in the dashboard.

How a redeploy works

Commit the change, then run scripts/deploy.sh demo gateway api ui nurse. It builds the images, updates Terraform and rolls out new versions in about five minutes; calls in progress finish on the old version.

Models in use

gemini-3.8-live

The phone conversation itself: listens and speaks in real time. Vertex AI, us-central1. Voice: Algenib.

gemini-3.8-flash

The Gemini Enterprise nurse agent, and reading free-text times in texts ("Tuesday after lunch"). It never decides triage.

gemini-2.5-flash-tts

Records the voicemail message once; it is cached and reused until the wording or voice changes.
